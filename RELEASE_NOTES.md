# Always Show Emoji Key 1.0.0

Always Show Emoji Key 1.0.0 is the first public release of the native emoji-key tweak for iOS 18.

## Highlights

- Keeps the native emoji key visible between `123` and the spacebar.
- Lets the native emoji key be tapped normally.
- Uses the native keyboard keyplane and key views.
- Does not use a custom key, overlay, or manual key placement.
- Does not change the keyboard language list or the Emoji keyboard setting.
- No preference pane or configuration is required.

## Compatibility

| Build | Architecture | Compatibility |
|---|---|---|
| RootHide | `iphoneos-arm64e` | Tested on iOS 18.4.1 (Dopamine 3, RootHide) |
| Rootless | `iphoneos-arm64` | Expected to work on iOS 18+ rootless jailbreaks |

Tested on iOS 18.4.1 (Dopamine 3, RootHide) on iPhone 11 Pro Max. The tweak requires iOS 18.0 or later. The rootless build was not independently tested.

## Install

1. Download the deb matching your jailbreak.
2. Install it with Sileo, Zebra, or Filza.
3. Respring if the keyboard does not reload automatically.

## Verification

Verify the downloaded deb against `SHA256SUMS.txt` before installing it.
